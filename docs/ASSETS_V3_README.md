# Activos v3

La nueva sección **Equipos y electricidad** complementa el Workspace de Activos. Su objetivo es que una papelería creativa/taller de sublimación pueda distinguir equipos de bajo consumo (impresoras/plotters) de cargas térmicas altas (prensas, hornos, laminadoras), registrar datos de placa y mantener una base de repuestos y métricas de desgaste.
