# Alcance de seguridad eléctrica

El módulo de Activos registra y compara datos de placa para ayudar a organizar el taller. No sustituye diseño eléctrico profesional.

- Verificar siempre placa y manual del fabricante.
- No usar una potencia de referencia de otro modelo como si fuera la del equipo propio.
- No asumir que una regleta, extensión, UPS o regulador admite una prensa, horno o laminadora de alta potencia.
- Registrar por separado las cargas auxiliares de un láser (extractor, bomba/chiller, compresor, etc.).
- Si el circuito, el enchufe, el cableado o la protección no están identificados, el ERP debe marcar la ficha como pendiente de verificación.
- Las decisiones de calibre de conductor, breaker, puesta a tierra, GFCI/RCD y circuito dedicado deben ajustarse al manual y a la normativa local aplicable.
