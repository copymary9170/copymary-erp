# Validación Activos v3

- [ ] El Workspace de Activos carga sin perder Registro y ficha.
- [ ] La sección Equipos y electricidad muestra perfiles técnicos.
- [ ] Una ficha eléctrica puede vincularse a un activo existente.
- [ ] Una ficha puede registrar voltaje, W, A, circuito y protección.
- [ ] La alerta de placa no verificada aparece en Resumen.
- [ ] Las cargas de 1000 W o más se distinguen en Resumen.
- [ ] El cálculo P/V se presenta como estimación, no como diseño eléctrico.
- [ ] Mantenimiento y Reemplazo continúan disponibles.
