# Matriz de equipos — Papelería creativa y sublimación

| Familia | Equipo | Métrica de desgaste sugerida | Elementos críticos |
|---|---|---|---|
| Papelería creativa | Impresora de tinta continua | Páginas impresas | cabezal, rodillos, caja/almohadilla de mantenimiento, tintas |
| Sublimación | Impresora dedicada | Páginas impresas | cabezal, tintas de sublimación, mantenimiento residual |
| Papelería creativa | Plotter de corte | Metros de corte | cuchilla, tapete, rodillos, calibración print & cut |
| Papelería creativa | Laminadora térmica | Metros laminados | rodillos, resistencia, sensores, arrastre |
| Sublimación | Prensa térmica plana | Planchados | resistencia/plato, controlador, relé, teflón/protector |
| Sublimación | Prensa de tazas | Ciclos de prensado | manta/resistencia, controlador, conectores |
| Sublimación | Horno dedicado | Horas de uso | resistencias, ventilador, termostato, sellos |
| Papelería creativa | Aplicadora de foil | Estampados | rodillo/silicona, resistencia, termostato |
| Papelería creativa | Anilladora | Perforaciones | punzones, palancas, motor si aplica |
| Papelería creativa | Guillotina eléctrica | Cortes | cuchilla, barra de corte, motor, sensores/guardas |
| Papelería creativa | Láser | Horas de uso | lente, espejos, extractor/filtro, tubo/módulo, rieles |
| Soporte | Computadora | Horas de uso | fuente/adaptador, ventiladores, SSD, batería |
| Soporte eléctrico | UPS/regulador/protector | Horas energizado | batería, fusible, ventilador |

Las métricas son categorías de seguimiento, no vidas útiles universales. Los intervalos deben salir del manual del modelo real o del historial operativo del negocio.
